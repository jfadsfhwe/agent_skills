Short version

Ontology + LLM

A chatbot that reads a Brick model and answers in plain language.

01 — Objective

A dialog with the model and the ontology

  • Chat with an LLM that knows the Brick model.
  • Upload your own Brick ontology.
  • Ask questions in natural language.
  • Read the query result back as prose.

02 — Framework

GPT-4 alone was not enough

03 — Preprocess

Turn the Brick file into paragraphs

  • Models know prose. They do not know RDF.
  • Rewrite each triple as a sentence the model can read.

TLVL-RF-ACC-01.AUTO is a Manual_Auto_Status. It has a Sensor tag. It is a point of TLVL-RF-ACC-01.

04 — LlamaIndex

The interface between people and data

  • LLM loader: run the model in a container.
  • Data loader: Brick, SQL, or a web page.
  • Query engine: ask domain questions.
  • Ship it as a chat app or a web service.

05 — Model

Zephyr-7B-beta

  • Released by Hugging Face in November 2023.
  • About 13 GB of RAM, a quarter of a 70B model.
  • Strong enough at reasoning and extraction to read a Brick model.

06 — Loaders

Plug in a model, then feed Brick

07 — NebulaGraph

Store the ontology as a graph

  • Relationships are the point of a Brick model.
  • NebulaGraph keeps nodes and edges, not rows.
  • The model can use that structure without writing SPARQL.

08 — Query engines

Two ways to ask

Graph RAG

Read the whole paragraph, then use the graph to check the answer.

Graph + vector RAG

Split the text first so the model can focus, then check the graph.

10 — Chiller 01

Explain the point, then read the table

“Explain the chiller 01 COP in TLVL.”

COP is the point TLVL-RF-ACC-01.COP. The series is 4132912_TLVL-RF-CHR-01-COP_TL Archive. A higher COP means the chiller is more efficient. The same story can be read from return temperature TLVL-RF-ACC-01.RETTEMP.

11 — Where it stands

Limits now, and what 2024 might change

Limitation

  • Open models still trail OpenAI on large, complex queries.
  • Ontology and timeseries still need two engines. Nothing queries both at once.

Hope

Meta’s Llama 3 and the open-source frameworks around it were the bet for a real step up in 2024.
